# Tinnis · 沿线小镇

浏览器三维日式地方铁路与微缩小镇经营游戏。当前完成 **首版 0.1.0（阶段 9、10）**，具备引导、完整存档恢复、经营、双车调度、成长支线与昼夜旅行体验。最终验收结果见 VALIDATION.md。

## 启动

直接试玩发行包：解压后进入“沿线小镇”文件夹，运行 `python3 -m http.server 8080`，打开 `http://localhost:8080`。无需安装Node依赖，断开互联网也能启动；不要直接双击HTML。下面是源码开发方式。

Node.js 24+（本环境 24.19.0 / npm 11.9.0），支持 WebGL2 的浏览器：

```sh
cd /workspace/Tinnis
npm ci
npm run dev
```

开发服务为 `0.0.0.0:5173`。其他电脑进入自己的仓库目录即可。`.nvmrc` 固定 Node 版本；`.npmrc` 使用仓库内忽略的 npm 缓存，适应云环境目录权限。

## 开始经营

1. 在「车站」选择 A 汐港和 B 青溪，各花 8000 建站；在「铺轨」选择 A/B 候选节点，预览并确认三段主线，共 12000。可分段建造，重复工程不重复收费，轨道限于预设走廊。
2. 在「列车」购置轻型 22000/24 人或大容量 38000/48 人，选择始发站投放。最多持有两车，点击车号切换；A 一泊位、B 两个独立会让泊位。目标泊位、完整区段和站口都空闲才发车，等待原因显示在列车页。选中车不改变调度优先顺序。
3. A—B 单程 90 游戏分钟，默认停站 10 分钟，自动制动、停站、折返；可跟车。旅客按站对、聚落规模和时段生成，有直达服务才接受，FIFO 上车，满载拆批并保留排队时间，默认 240 分钟耐心。到站先下后上，其他目的地旅客留在车上。每站最多显示 6 个统计人物，无逐居民 AI。
4. 「经营」设置基础票价 10—30（默认 20）、同方向目标间隔 120/180/240 分钟。站对票价按路程系数计算；低价接受率更高，上车锁价，完成旅程按唯一事件入账。间隔还受车辆数、周转和信号影响，面板显示当前下限/周转与最近实际间隔。
5. 账本收取车辆固定费、站轨维护费和实际行驶里程费；暂停不计时不收费，午夜只汇总。经营净收益为票款＋租金−固定费−里程费−维护费，购建/升级与资产出售另列现金流。资金不足禁止投资，耗尽后停止新发车，在途完成当前单程到站停运，欠款保留。安全停站或车库的空车可按原价 60% 出售恢复经营；退款即使不足以抵清欠款也会入账。
6. 「成长」选择已建车站改善站区。候车设施 3000、维护 20/日、耐心 +120 分钟；站台服务 4500、维护 35/日、停站缩至 6 分钟；商店 6000、维护 60/日、每名实际到达旅客带来 2 元租金。每项一级，可单独拆除退原价 50%；拆站前先拆升级。
7. 聚落按时段运量、候车压力、服务稳定性累计进度，最多三级，每次成长至少间隔一游戏日。固定地块替换住宅/商业/旅馆表现，需求规模为 1/1.4/1.9。无服务暂停成长，原因、进度和冷却在成长页显示。
8. 累计送达 200 人并有一个**完整盈利运营日**后，开放 D 枫泉旅游权限。初始 08:00 开始的部分日不算完整日，没有解锁赠款。仍须支付 D 站 8000、B—D 三段轨道 8000；成长页可设 A—B—D 停站。先完成建设，再从列车页投放；可把一车单独指派 A—B，另一车指派 A—B—D，共享 AB 区段，途中 B 停站。B—D 按路长约 136.9 游戏分钟。C 河谷保持可选预留。

轨道/车站可拆除，返原购建价 50%，每实例只退一次。运营及待应用线路依赖受保护，先安全停运、送完乘客，再收车回库或出售。人为长期停占 A 会阻塞后车，需恢复或收车；不会自动瞬移、穿车或删车。

## 画面旅行与声音

地图上方旅行条可选择「俯瞰」「跟车」「乘客观景」。先投放并选中车辆，再跟车或沿轨道旁前方看风景；乘客观景固定镜头，缩放按钮暂时禁用。镜头切换平滑过渡，视线遇到景观或其他车辆时自动抬升避让。「更多」可快速定位 A/B/D、调整总音量；俯瞰保留旋转、平移和缩放。窄屏可收起经营面板，横屏也保留旅行控制。

昼夜由模拟时钟驱动，5—8点渐亮、17—20点渐暗，夜间站灯、灯下光斑和车窗点亮。天气可自动/晴/雨，自动周期的12—18点为雨天；384条轻量雨线只影响观感，不改需求、费用或信号。暂停时游戏时钟和雨景时刻冻结，镜头仍可切换观察。

首次可信点击或按键后启用本地合成环境/行车声，到站播放一次短音。旅行条支持总静音与音量，默认35%；隐藏页面暂停声音，读档不补播历史到站。声音不使用外部音频或网络请求，视角与声音操作不重置模拟累积步长。

## 观察与存档

| 操作 | 电脑 | 触屏 |
| --- | --- | --- |
| 旋转 | 左键拖动 | 一指拖动 |
| 平移 | 右键拖动 | 双指拖动 |
| 缩放 | 滚轮 / ＋ − | 双指捏合 / ＋ − |
| 选择/取消 | 点击站位；Esc 或空地 | 点击站位或空地 |
| 建设/经营 | 工具页、候选节点、确认面板 | 同左，面板可收起 |
| 暂停 | Space / 底栏 | 底栏 |
| 全景 | Home / 房屋按钮 | 房屋按钮 |

相机限制距离、俯角与平移边界。切后台冻结模拟，不补算后台时间；1 倍速为每现实秒 2 游戏分钟，支持暂停与 1/2/4 倍速。规则按固定步长更新，独立于画面帧数。

每 60 现实秒及成功修改后自动保存；右上「存档」可手动保存/读取、导入/导出 JSON。当前 **schema v9，兼容 v1—8**：旧世界、现金、资产和列车保留；旧完成票款只结算一次，旧费用不追缴；单车旧档迁移真实许可，双车 v6 保留资源状态并迁移同方向间隔历史。v8另保存旅行/天气/静音/音量/定位偏好和近景相机，v7跟车偏好迁移；费用与旅程不重放。保存队列原时间、车上锁价、唯一到达/票款、费用余数、两车位置/许可、升级、成长、租金与解锁。读取核对账本、资产凭据、容量、人数守恒及资源占用；无效导入不替换世界。旧 localStorage 键保留，后续写 v9。

新游戏有可跳过的八步引导，依次提示建站、铺轨、购车投放、查看候车/收支和首趟运输；里程碑按真实经营记录留念，不发现金奖励。存档面板可开始新游戏、继续、恢复上次有效存档或最近正余额存档。新游戏先保存当前世界；恢复会一并回退时间、账款和资产，并非清除欠款。损坏的主档优先读有效备份，未知版本或无效导入不覆盖当前进度。v9保存引导/查看记录和里程碑，旧经营档默认跳过引导，可自行恢复。

存档保存在当前浏览器/站点，清理数据前导出备份。导入上限 8 MB，账目校验上限 100000 条；存储配额不足会提示导出。备份各保留一代，长期留存须导出JSON；长期历史归档属于后续优化，当前不自动删除审计历史。

## 验证

```sh
npm run check
npm test                 # 规则/迁移/财务/调度/成长
npm run build
npm run test:e2e          # 真实 Chromium：场景与建造 23 组
npm run test:train        # 单车三次往返、运行/制动/停站读档 7 组
npm run test:passengers   # 候车/满载/完成/放弃/离线/触屏 9 组
npm run test:business     # 经营表单、结算、迁移、暂停/读档 5 组
npm run test:dispatch     # 双车投放、等信号重载、交替/触屏 4 组
npm run test:growth       # 升级付费、D 建线、旅游运输、离线/触屏 6 组
npm run test:travel       # 跟车往返、乘客视角、昼夜雨景、声音/离线/触屏
npm run test:recovery     # 引导首趟、新游戏/备份、损坏导入、60秒自动保存、触控
npm run test:balance      # 三种正常经营配置十日对照
npm run test:release      # 同负载性能、资源复用、跨车型恢复、冷启动/离线
npm run verify           # 类型/规则/构建及全部浏览器回归
npm run test:soak         # 另行至少30分钟真实连续运行，不加速墙钟
```

浏览器检查先构建，脚本各自启动并清理预览进程，默认 `/usr/bin/chromium`（可用 `CHROMIUM_PATH` 覆盖）。截图、下载和报告位于忽略目录 `artifacts/`；实测结果、运行环境、性能限制和检查点见 [PROGRESS.md](PROGRESS.md)。`?diagnostics=1` 提供只读 `window.__ALONGLINE__.snapshot()`，正常界面不暴露调试数据。

## 离线发行

```sh
npm run build
npm run preview
# 或用已有静态服务，无需安装 Node 依赖：
python3 -m http.server 8080 --directory dist
```

先运行 `npm run verify`、`npm run test:balance`、`npm run test:soak`，再运行 `npm run package`，可在30分钟验收通过且发行目录与测试指纹一致后生成发行包、源码包和SHA256清单；它不重新构建候选。发行目录解压到 `artifacts/release-unpacked/沿线小镇` 后，`npm run test:packaged` 使用说明中的Python HTTP服务复核实际ZIP。打包还需Python3，运行发行只需任一本地HTTP静态服务。

完整 `dist/` 可复制/压缩发行，通过 HTTP 打开。Three.js、脚本、模型、SVG、样式和系统字体均本地打包，无运行时 CDN/远程资源。生产版在 HTTPS 或 localhost 首次访问后缓存完整资源，可断网重载；开发版不注册 service worker。
